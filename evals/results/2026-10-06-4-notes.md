### M10: why repetition got worse (suspects, not proven)

- The rise is all in Park Finds: 43 of 277 printed Park Find clues repeat across parks (14 of 238 before); Wild Finds
  11 of 127 (7 of 128).
- 28 of those 43 hold a 5-word run copied from the code-written fact sheets (`src/lib/pool/park.ts`), against 4 of 14
  before. The overall copy rate is about the same (82 of 277 Park Find clues hold a 5-word fact run, 74 of 238
  before); what changed is that the same phrases landed on 3 parks instead of 1-2. The metric counts a clue only when
  its run is on 2 or more OTHER parks, so a phrase moving from 2 to 3 parks flips every clue that holds it.
  Examples: "paths that cross over water" 2 -> 4 parks, "a base at every corner" 1 -> 3, "a tall net across the"
  1 -> 3, "has armrests at the ends" 0 -> 3 (a new word choice from round 3: `{arms|armrests}`).
- More Park Finds were printed (277 vs 238), because more passes were complete.
- The source-copy check is a preference since the content tuning (dropped only when a spare can replace it), and most
  pools ask for 0 spares, so copied fact phrases print.
- Possibly the round-3 prompt changes (no filler openers, "the source's describing words" style), which make clues
  start straight with the thing; not isolated in this run.

### M5, M6, M8: why they moved (suspects)

- **M5 1.7 -> 2.5:** round 3 removed the short filler openers ("Quick!", "Wow!", "Psst,") that code or the prompt
  used to add; they made short sentences and pulled the FK grade down. The new openers (Explore, Discover, Notice)
  have more syllables. Still well under 3.5.
- **M6 2.0% -> 3.7%:** round 3 widened what counts as a name word (Wikipedia's bolded other names, and the R3 name
  checks), and the scorer uses the app's `nameWords`, so more leaks are counted. Code removes every one before printing.
- **M8 $0.00070 -> $0.00089:** 21 refill calls instead of 10 (the stricter checks drop more items: generic_clue 55 vs
  30, duplicate_id 18 vs 8), and the first-call prompt is about 7% longer (median 2,635 prompt tokens vs 2,464).

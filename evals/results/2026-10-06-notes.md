## What changed in the app between run 4 and this run
- **Season fact in the SOURCE (Llama fix).** Each plant's source text now ends with a code-written sentence from the
  same iNaturalist "Flowers and Fruits" counts, for example "In October, iNaturalist photos from this area show it with
  flowers, not fruit." or "... do not show it with flowers or fruit." It replaced the `season="..."` tag attribute,
  which Llama 4 Maverick copied as its sourceQuote 22 times in run 4 (ungrounded, so dropped). The sentence is true,
  has no digits and no name words, so quoting it is grounded. The out-of-season drop rule is unchanged.
- **Count clues must not name the thing.** The prompt now says so, with a good and a bad example ("How many ways over
  the water can you find? There are 8." vs "Count the bridges."), lists plain "look where" places ("near the water",
  "on tree trunks", "by the path"...) and gives real bad examples from run 4 ("a kind of oak" for a bur oak, "flowers
  like trumpets" for a trumpet vine).
- **Source text that invited leaks.** The baseball field description no longer says "dirt diamond" (it says "a dirt
  infield with a base at each corner"), and "diamond" is now a baseball name word everywhere (before, only when the OSM
  name said "Diamonds"). The public-art description no longer says "sculpture, statue or mural" (all three are
  forbidden name words for that kind).
- **False name-leak matches removed (code).** From reading all 46 run-4 Gemma leaks (the scorer found 46 with run 4's
  code; the run-4 notes said 47):
  - 5 false: a word of the feature kind's own label inside an OSM name. "court" in "Taube Family Championship Court"
    (x3, tennis) and "field" in "North Meadow Soccer Field 5" (x2, soccer). The kind itself allows these words ("Count
    the hoops on the court." is the prompt's own good example), so an OSM name no longer forbids them
    (`kindLabelWords`). Words the kind forbids stay forbidden: "Baseball Diamonds" still blocks "diamond".
  - 1 false: a landscape word in an OSM name. "near a garden" for picnic shelters named "Jeanne's Pavilion at the
    Shadow Garden". Garden, meadow, field, grove, hill, woods, forest, ridge, point, plaza, square, commons, spring are
    now place words in OSM names (like park, trail, creek were already). A garden feature still forbids "garden".
  - 0 false from the stem rule in run 4. Across runs 2-4 (all models) the stem rule caught only real leaks except one:
    Llama's "a bright throat" for a ruby-throated hummingbird. Words ending in "-ed" (throated, painted, striped,
    crested) no longer get a stem; the whole word is still a leak.
  - The other 40 were real and are left to the prompt: count clues naming the thing (bridges x3, ponds, baseball
    fields), "dirt diamond" (x3), "a type of oak" (x3), "trumpets" (x3), "tree squirrel" (x3), "Columbidae", "by the
    stream" (x3), "near the river" for river oats (x3), "climbing on other plants" (x3), "in a garden" for garden
    nasturtium / garden snail, "at the edge of the lake", "sculpture or statue" (x2), "memorial" (x2), "a gray animal",
    "balloons", "a wren".
- **Contact filter on the Find This Spot target name**, **a failed season lookup marks the pass degraded**, and a
  **test clock pinned to the recording day** do not change eval numbers (Find This Spot is not in the eval; the eval
  replays recorded season answers).
